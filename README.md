# 🔍 Lost & Found

A web-based Lost & Found Management System that helps users report lost or found items and find possible matches. The project is designed for environments such as college campuses, hostels, offices, and communities.

# ✨ Features

- 🔐 User registration and login
- 📢 Report lost items
- 📦 Report found items
- 🔎 Find possible matches between lost and found items
- 📱 View and manage reported items
- 📞 Access contact details for matched items
- ✅ Mark items as recovered
- 📋 View recovered item history
- 🔥 Firebase-based authentication and database

# 🛠️ Technologies Used

- HTML5 – Structure of the web pages
- CSS3 – Styling and responsive design
- JavaScript – Application logic and interactivity
- Firebase Authentication – User authentication
- Cloud Firestore – Database for storing item and user information

# 🔄 How It Works

1. Register/Login – Users create an account or log in.
2. Report Lost Item – Users provide details about an item they have lost.
3. Report Found Item – Users can report an item they have found.
4. Match Items – The system compares details such as item type, color, location, and description.
5. Recover Item – When a match is found, users can contact each other and recover the item.
6. Recovery History – Recovered items are recorded for future reference.

# 🔥 Firebase

The application uses Firebase for backend services:

- Firebase Authentication for account management.
- Cloud Firestore for storing users, lost items, found items, and recovered items.
